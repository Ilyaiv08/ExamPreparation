# Подготовка к демоэкзамену 09.02.07

Интерактивная платформа подготовки к демонстрационному экзамену по специальности
**09.02.07 «Информационные системы и программирование»**, квалификация
*Разработчик веб и мультимедийных приложений*.

Цель — довести студента до состояния, в котором он за четыре часа собирает
работающее веб-приложение с базой данных, регистрацией, ролями и админкой.

Платформа построена на двух реальных источниках: 7-месячной программе
подготовки и задании демоэкзамена (вариант № 2). Сами файлы — учебные
материалы колледжа, в репозитории их нет; всё, что платформа из них берёт,
уже лежит в коде: план — в `content/curriculum/plan.generated.json`,
требования экзамена с дословными цитатами — в `content/exams/`.

---

## Что внутри

- **План на 210 дней** — теория, практика, повторения, контрольные.
  У каждого дня своё практическое задание, у седьмого дня недели — сборка
  из всего, что появилось за неделю.
- **104 темы теории** — суть, подробный разбор, примеры, типичные ошибки
  с объяснением причины.
- **210 практических заданий, 1280 тест-кейсов.** Код студента исполняется
  по-настоящему в песочнице прямо в браузере — пять сред: JavaScript,
  TypeScript, DOM, React, SQL. Оценка по пройденным тестам, а не по
  совпадению текста.
- **104 теста по теории, 520 вопросов** шести типов, у каждого — пояснение.
- **7 мини-проектов** с ТЗ, чек-листом и частичной автопроверкой.
- **Режим «ДЕМОЭКЗАМЕН»** — три модуля, отдельные таймеры, 25 требований
  с дословными цитатами задания. Плюс тренировочные варианты на других
  предметных областях.
- **Интервальное повторение**, прогресс по месяцам и технологиям, слабые
  темы с объяснением словами, оценка готовности с раскрытием расчёта.
- **Работа офлайн** — все библиотеки локальные, как на экзаменационном
  компьютере.

## Стек

Next.js 16 (App Router) · React 19 · TypeScript 5.9 (строгий режим, `any` нет) ·
Tailwind CSS 4 · Prisma 6 + SQLite · JWT в httpOnly-cookie + bcrypt ·
Monaco Editor · sql.js (SQLite на WebAssembly) · Vitest + Playwright.

Почему именно так — [`docs/DEVELOPMENT.md`](./docs/DEVELOPMENT.md).

## Быстрый старт

Нужен Node.js 20.9+ и npm 10+.

```bash
git clone https://github.com/Ilyaiv08/ExamPreparation.git
cd ExamPreparation
npm install
cp .env.example .env
```

В `.env` задайте свой `AUTH_SECRET` (не короче 32 символов):

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
```

Дальше — база и запуск:

```bash
npm run setup
npm run dev
```

Откройте <http://localhost:3100>. Администратор: логин `admin`, пароль —
значение `ADMIN_PASSWORD` или `admin12345`, если переменная не задана.

Подробнее про `.env`, PostgreSQL, резервные копии и админку —
[`docs/DEVELOPMENT.md`](./docs/DEVELOPMENT.md).

## Команды

| Команда | Назначение |
|---|---|
| `npm run dev` | Сервер разработки на порту 3100 |
| `npm run build` / `npm start` | Сборка и запуск собранного приложения |
| `npm run setup` | База + данные + локальные библиотеки песочницы |
| `npm test` | 159 модульных и интеграционных тестов (Vitest) |
| `npm run test:e2e` | Сценарные тесты в браузере (Playwright) |
| `npm run test:solutions` | Эталонное решение каждого из 210 заданий — через настоящую песочницу, около 10 минут |
| `npm run content:check` | Целостность контента: битые ссылки, дубликаты, расхождения баллов |
| `npm run lint` / `npm run typecheck` | ESLint / проверка типов |
| `npm run assets` | Пересобрать локальные библиотеки песочницы |

Перед коммитом:

```bash
npm run typecheck && npm run lint && npm run content:check && npm test
```

## Чего платформа не делает

Сказано прямо, чтобы не возникало ложных ожиданий:

- **Не заменяет экзамен.** Настоящий демоэкзамен — четыре часа в VS Code
  с сервером, базой и Git. Платформа тренирует части этой работы и даёт
  чек-листы для остального.
- **Не предсказывает оценку.** Процент готовности — внутренняя метрика.
  Официальной шкалы в задании нет, веса требований — обоснованное решение
  разработчика, а не документ.
- **Не проверяет ваш проект.** ER-диаграмму, коммиты и внешний вид приложения
  в вашем репозитории отмечаете вы сами.
- **Не выдумывает содержание экзамена.** Официальный вариант один. Всё
  остальное помечено как авторское.
